# 📚 مكتبتي التعليمية

موقع بسيط لتنظيم دروس الفيديو وملفات الـ PDF لترمين دراسيين، مع تتبع تقدم، وضع ليلي، لائحة مهام، وسجل نشاط كامل.

## الصفحات
| الملف | الوصف |
|---|---|
| `index.html` | صفحة تسجيل الدخول (حماية بسيطة بكلمة سر من جهة المتصفح) |
| `terms.html` | اختيار الترم (اول / تاني) |
| `home.html` | مكتبة ترم اول |
| `home2.html` | مكتبة ترم تاني |
| `pdf.html` | مكتبة ملفات PDF وروابط خارجية |
| `styles.css` | التنسيقات المشتركة لكل الصفحات |
| `app.js` | كل المنطق البرمجي المشترك (تقدم، وضع ليلي، مودال الفيديو، الشريط الجانبي، لائحة المهام، السجل) |

## مميزات
- ✅ تتبع تقدم لكل مادة + شريط عام، محفوظ في المتصفح (localStorage)
- 🌙 وضع ليلي موحّد ومحفوظ بين الزيارات
- 🎬 نافذة تشغيل للدروس (يوتيوب / جوجل درايف) بدل الخروج من الصفحة
- 📚 شريط جانبي بملخص تقدم كل مادة، وتذكير بمراجعة الدروس اللي فاتها 4 أيام
- 📋 لائحة مهام بسيطة
- 📒 سجل بكل درس اتفتح وإمتى، قابل للتصدير/الاستيراد
- 📤 تصدير/استيراد كامل بيانات التقدم كملف JSON

## ملاحظات تقنية
- كلمة السر في `index.html` تتغيّر من نفس الملف (متغير `SITE_PASSWORD`) — الحماية شكلية فقط ومش بديل عن حماية حقيقية من السيرفر.
- خدمة تسجيل النشاط في جوجل شيت اختيارية، وبتفشل بهدوء لو مفيش اتصال بالنت.
- الموقع ثابت بالكامل (Static) — يفتح مباشرة من أي استضافة مثل GitHub Pages بدون أي إعداد إضافي.
